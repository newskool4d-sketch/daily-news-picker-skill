# Examples (골든 레퍼런스 아카이브)

소통협력담당관이 실제로 공유한 일일 언론보도 현황 문안을 정본 예시로 보관한다.
스킬이 목표로 하는 **실제 공유 형식·범위·매체 다양성**의 기준점이다.

## 사용 목적

- 출력 형식 검증: `■ 기사 제목 - 매체명` + 다음 줄 URL 형식의 정본 확인
- 커버리지 기준: 본청·5개 지원청·직속기관·도서관·학교 현안이 한 회차에 어떻게 섞여 들어오는지 실측 분포 확인
- 매체 로스터 점검: 새 회차에서 [media-sources.md](../references/media-sources.md)에 없는 매체가 보이면 즉시 추가

## 관찰된 시사점 (2026-06-26 기준)

- 직속기관·도서관은 **개별 기관명만으로** 보도되는 경우가 많다 → `search-recipes.md`의 Q5 필수 루프 근거.
- 교육감 외부 직위(학교체육진흥회 이사장)는 본청 키워드로 누락 → Q4 `인천교육감` 쿼리 근거.
- 전자신문 에듀플러스·스포츠조선 등 전국 전문지가 인천교육 사안을 다룸 → 로스터의 전국지 티어 보강 근거.
