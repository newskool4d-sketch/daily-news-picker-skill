# Coverage Tracking (역방향 게재 추적)

배포한 보도자료 1건이 **실제로 어느 매체에 게재됐는지**를 역추적하는 모드.
일일 수집(`daily-news-picker` 기본 모드)과 방향이 반대다.

## 기본 모드와의 핵심 차이 (반드시 숙지)

| 구분 | 일일 수집(기본) | 게재 추적(역방향) |
|---|---|---|
| 목적 | 당일 전체 언론보도 현황 | 특정 보도자료의 게재 성과 |
| 보도자료 전재본 | **제외/참고로 강등** | **포함 — 곧 게재 성과** |
| 중복 처리 | 동일 사건 1건만 대표 | 전재 매체를 **모두 카운트** (매체 수가 성과 지표) |
| 입력 | 기관명·기간 | 보도자료 제목·배포일·핵심어 |
| 산출 | 주요 언론보도 현황 | 게재 매체·URL·게재일 표 + 게재 매체 수 |

> daily-news-picker 기본 규칙(보도자료 전재 제외)을 이 모드에 그대로 적용하면 성과가 0으로 나온다. 이 모드에서는 전재본이 정답이다.

## 입력

- **제목**: 배포 보도자료 제목 (예: `인천교육청, 농어촌 유학 학부모 홍보단 발족`)
- **배포일**: `YYYY.MM.DD`
- **핵심어**: 기사에서 거의 변형되지 않는 고유 행사·사업·기관명 (예: `농어촌 유학`, `학부모 홍보단`). 일반어(`연수`, `운영`)는 단독 사용 금지.

## 추적 창 (window)

- 기본: 배포일 ~ 배포일 + 3일 (보도자료는 통상 배포 당일~3일 내 게재).
- 주말·공휴일은 추적 창에 포함하되, 게재일 검수 시 영업일 보정.
- 게재가 계속 나오면 +5일까지 연장 가능. 연장 여부를 산출물에 명시.

## 검색 전략 (순서)

1. **핵심어 네이버 뉴스 검색** (기간 필터) — [search-recipes.md](./search-recipes.md)의 Jina 패턴 재사용. 검색어는 `{핵심어}` (기관명 AND 고유 행사명 조합).
2. **로스터 전 도메인 site: 스윕** — [media-sources.md](./media-sources.md)의 전 도메인에 `site:{domain} {핵심어}` 를 추적 창 안에서 실행. 일일 모드의 "저수집 시에만"과 달리, 추적 모드에서는 **로스터 전체를 매번 스윕**한다 (게재 매체 누락이 곧 성과 누락).
3. **제목 특징 구절 보강** — 제목에서 12자 내외 고유 구절로 추가 검색해 1·2단계 누락분 회수.
4. **공식 보도자료 원문 확인** — `site:ice.go.kr {핵심어}` 로 배포 원문을 찾아 제목·배포일·핵심 사실을 확정 (게재 판정 기준점). 단, ice.go.kr 자체는 "게재 매체"로 카운트하지 않는다.

## 게재 판정·분류

각 발견 기사를 다음으로 분류한다:

- `전문 전재`: 보도자료 원문을 거의 그대로 게재 (제목·문단 일치).
- `부분 게재`: 보도자료 기반이나 요약·발췌·제목 변형.
- `자체 취재`: 기자가 추가 취재·코멘트·재구성 (가장 가치 높음).

판정은 게재 여부에 영향을 주지 않는다 — 셋 다 게재로 카운트한다. 분류는 질적 참고용.

## 산출 형식

```text
[게재 추적] {제목}
배포일: YYYY.MM.DD / 추적 창: YYYY.MM.DD ~ YYYY.MM.DD
게재 매체 수: N개 (전문 전재 a · 부분 게재 b · 자체 취재 c)

| 매체 | 게재일 | 구분 | URL |
|------|--------|------|-----|
| 연합뉴스 | YYYY.MM.DD | 자체 취재 | https://... |
| ...  | ...    | ...  | ... |

미게재/미확인: (없으면 생략)
- 스윕했으나 게재 확인 안 된 로스터 매체 수 또는 특이사항
```

## 규칙

- **허구 방지**: 실제 resolve되는 기사 URL만 수록 (일일 모드와 동일). 게재 매체 수를 부풀리지 않는다.
- **중복 URL 1회**: 같은 기사 URL은 한 번만. 단 동일 매체가 별도 기사로 2건 게재하면 2건 모두 카운트.
- **로스터 밖 매체**: 로스터에 없어도 기자 명의 게재면 카운트하고, 새 도메인은 [media-sources.md](./media-sources.md)에 추가.
- **미게재 처리**: 추적 창 내 게재가 0건이면 "게재 확인 안 됨"으로 솔직히 표기하고, 스윕한 매체 수·검색어를 함께 남긴다.
- **저장**: 요청 시 `게재추적_{핵심어}(YYYYMMDD)` 폴더에 md로 저장. 일일 현황 산출물과 폴더를 분리한다.
