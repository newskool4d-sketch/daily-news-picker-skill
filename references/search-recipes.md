# Search Recipes (검증된 검색 레시피)

> 2026-06-12 `ice-news-briefing`(구 Claude 스킬) 통합 시 실측 검증 후 작성.
> 모든 쿼리는 실제 호출로 작동을 확인한 패턴만 수록한다. 작동하지 않는 패턴은 하단 "금지 패턴"에 사유와 함께 기록한다.

## 날짜 변수

- `{DS}` = 시작일 `YYYY.MM.DD` / `{DE}` = 종료일 `YYYY.MM.DD`
- `{FROM}` = 시작일 `YYYYMMDD` / `{TO}` = 종료일 `YYYYMMDD`
- 기본 창: 직전 점검 이후 ~ 현재 (평일 07:00 기준). 월요일은 금~일 누적 포함.

## 1차 필수 쿼리 (병렬 실행, 네이버 뉴스 날짜필터)

Jina Reader 경유 패턴 (2026-06-12 작동 확인):

```text
https://r.jina.ai/https://search.naver.com/search.naver?where=news&query={검색어}&sort=1&ds={DS}&de={DE}&nso=so:r,p:from{FROM}to{TO}
```

| # | 검색어 | 목적 | 실측 상태 |
|---|---|---|---|
| Q1 | `인천교육청` | 본청·교육감·시교육청 표기 전반 (네이버 형태소 매칭으로 `인천시교육청` 포함) | ✅ 2026-06-12 작동 확인 |
| Q2 | `인천교육지원청` | 5개 교육지원청 (개별 명칭 `인천북부교육지원청` 등 포함 매칭) | ✅ 작동 (간헐 오류 → 재시도 규칙 적용) |
| Q3 | `인천 학생교육원` | 학생교육원 (사용자 소속 기관, 최우선 커버리지) | ✅ 2026-06-12 작동 확인 |
| Q4 | `인천 AI융합교육원` | 직속기관 보강 (필요 시 `인천 교육연수원`, `인천교육청 도서관` 등 동일 패턴으로 추가) | 패턴 동일 — Q3와 같은 AND 방식 |

검색 도구가 Jina/직접 fetch가 아닌 내장 웹 검색(`codex exec --search` 등)일 때도
**동일한 검색어 세트**를 사용하고, 날짜 조건은 검색어에 기간을 명시하거나 결과에서 날짜를 검수한다.

## 재시도 규칙

- 네이버가 `일시적인 오류로 정보를 표시할 수 없습니다`를 반환하면 **1회만 재시도** (간격을 두고).
- 재시도도 실패하면 해당 쿼리를 건너뛰고 브리핑에 `[수집 실패: Q# 검색어]`를 명시한다. 조용한 누락 금지.
- `입력하신 검색어가 길어 ... 까지만 검색된 결과입니다` 안내가 보이면 검색어가 잘린 것이다. 그 결과를 쓰지 말고 검색어를 분할한다.

## 금지 패턴 (실측 근거)

| 패턴 | 사유 | 실측일 |
|---|---|---|
| 다중 기관 `OR` 쿼리 (`학생교육원 OR AI융합교육원 OR 남부교육지원청 OR ...`) | 네이버 검색어 길이 제한으로 7개 항목 중 뒷부분이 잘림 + OR 쿼리에 반복적 `일시적인 오류` 반환 | 2026-06-12 |
| 지역지 섹션 직접 수집 (인천일보 `sc_sub_section_code=S2N14`, 기호일보 `S2N36`) | JS 렌더링으로 섹션 필터가 적용되지 않은 전체 피드만 반환됨. 네이버 뉴스가 해당 지역지(기호일보·경인일보 등)를 색인하므로 1차 쿼리로 커버됨 (실증: 일일 브리핑의 기호일보·경인일보 기사가 네이버 검색에서 수집됨) | 2026-06-12 |
| 지역지 키워드 검색 (`sc_word=인천교육청`) | 동일하게 필터 미적용 전체 피드 반환 | 2026-06-12 |

## 허구 방지 원칙 (엄수)

- 검색 결과에 없는 기사 제목·URL을 임의로 생성하는 것은 **절대 금지**.
- 결과가 없으면 "검색 결과가 없습니다"로 솔직하게 표기한다.
- 수록 전 URL이 실제 기사 원문으로 연결되는지 확인한다. 404·리다이렉트 의심 URL만 추가 fetch로 검증하고, 검증 실패 URL은 제외한다.
