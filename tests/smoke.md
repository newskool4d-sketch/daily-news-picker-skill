## 수동 실행 방법

```text
Use $daily-news-picker at %USERPROFILE%\.codex\skills\daily-news-picker\SKILL.md.
```

실행 후 확인 순서:

1. 검색 레시피의 쿼리 세트가 실제 사용됐는지 (OR 쿼리·지역지 섹션 URL 미사용)
2. 최종 기사 수와 `핵심 요약`/`선별 기사`/`제외 또는 참고` 구조
3. `인천교육청 언론보도 현황(YYYYMMDD)` 폴더에 md+html 존재
